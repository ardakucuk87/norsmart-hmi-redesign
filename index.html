Things to try

  • Switch the language with the EN / TR button at the top of the display.
  • Pick “Ready to regenerate”, then run the regeneration on the Exhaust screen.
  • Pick “Discharging at rear” and watch the drum on the Mixer screen.
  • Pick “Brake sensor fault” and see Sensor fault instead of a false 0 bar.
  • Press Unplug CAN and see every value turn to ––.
  • Open Diagnostics › CAN bus to watch the real BYM6 frames.
  • Service: log in as Maintenance and change a parameter. Then undo it.
  • Press the Brake TEST key and run the brake test.
  • Switch to Day mode with the sun button at the top right.
